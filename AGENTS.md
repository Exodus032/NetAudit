# UI verification

After changing any frontend UI source (including CSS, HTML, TSX, or JSX), run
the application and visually inspect the affected screen before completing the
task. Use the available browser or screenshot capability and verify both a
desktop viewport and a narrow viewport when the layout is responsive. Report
the visual check and any fixes made from it in the final handoff.

The project `.codex/hooks.json` also enforces a final reminder for UI edits.
